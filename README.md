# 🛡 Свой VPN-сервис для Happ — установка за ~10 минут

Комплект поднимает полноценный сервис на вашем VPS:

| Компонент | Зачем |
|---|---|
| **Marzban** | веб-панель: пользователи, лимиты трафика, сроки действия, статистика |
| **Xray + VLESS Reality** | сам туннель; маскируется под обычный HTTPS, устойчив к блокировкам |
| **nginx** | прокси к панели + подписки по HTTPS после привязки домена |
| **Happ** (клиент) | ваши клиенты ставят его и подключаются по ссылке/QR/подписке |

Протокол выбран не случайно: **VLESS + Reality** — сейчас лучший вариант именно под Happ
(поддерживается на всех платформах: iOS, Android, Windows, macOS, Linux, TV).

## Схема работы

```
порт 443            -> трафик клиентов (маскировка под обычный HTTPS)
порт 8080           -> панель, доступ ТОЛЬКО через SSH-туннель (закрыт файрволом)
порт 80             -> веб (и продление сертификатов)
порт 8443           -> подписки клиентам по HTTPS (появится после привязки домена)
```

---

## 0. Требования к VPS

- **ОС:** Ubuntu 22.04 / 24.04 или Debian 12 (64-bit) — чистая установка.
- **Ресурсы:** от 1 vCPU / 1 ГБ RAM / 10 ГБ диска. Хватает на 20–40 активных клиентов.
- **Локация:** любая страна вне РФ (Нидерланды, Германия, Финляндия и т.п.) — ближе к пользователям = быстрее.
- **Виртуализация:** только KVM (не OpenVZ).
- **Порт 443 должен быть свободен** и не закрыт у хостера.

> 💡 После оплаты хостер пришлёт **IP, логин (обычно `root`) и пароль**. Это всё, что нужно.

---

## 1. Подключаемся к серверу

**С компьютера (терминал / PowerShell / PuTTY):**

```bash
ssh root@IP_ВАШЕГО_СЕРВЕРА
```

Введите пароль из письма хостера (при вводе он не отображается — это нормально).

**С телефона** (если настраиваете оттуда): приложение **Termius** (iOS/Android) → New Host →
IP, логин, пароль.

---

## 2. Загрузка и установка комплекта

Закиньте папку `happ-vpn-service` на сервер любым способом (самый простой — по SCP
с вашего компьютера):

```bash
scp -r happ-vpn-service root@IP_ВАШЕГО_СЕРВЕРА:/root/
```

Затем на сервере:

```bash
bash /root/happ-vpn-service/install.sh
```

Скрипт сам поставит Docker, nginx, панель Marzban и ядро туннеля. В конце он напечатает
**логин и пароль панели** (они же сохраняются в `/root/marzban-setup.txt`). **Сохраните пароль!**

Установка занимает 3–7 минут в зависимости от скорости сервера.

---

## 3. Заходим в панель

Панель **намеренно закрыта от интернета** — открывается только через SSH-туннель.
На своём компьютере выполните:

```bash
ssh -L 8443:127.0.0.1:8080 root@IP_ВАШЕГО_СЕРВЕРА
```

Затем, не закрывая терминал, в браузере:

```
http://127.0.0.1:8443/dashboard
```

Введите логин/пароль из шага 2. Готово — вы в панели.

---

## 4. Настройка сервера в панели (делается один раз)

1. Слева: **Inbounds** → кнопка **создать** (плюс).
2. Заполните:
   - **Название:** `Main`
   - **Протокол:** `VLESS`
   - **Безопасность:** `Reality`
   - **Порт:** `443`
   - **Ключи:** нажмите кнопку-«кубик»/«генерация» рядом с полем **Private Key** —
     пара ключей создастся сама, публичный ключ подставится автоматически.
   - **SNI / dest:** `www.speedtest.net:443` (можно любой крупный сайт с 443-м портом)
   - **uTLS:** `firefox`
   - **Short ID:** любое, например `ab12cd34`
3. Сохраните. Статус входящего подключения должен стать 🟢.

> Если смените порт (не 443), не забудьте открыть его: `sudo ufw allow НОВЫЙ_ПОРТ/tcp`.

---

## 5. Создание пользователей (ваши клиенты)

1. Слева: **Users** → **Add User**.
2. Заполните:
   - **Имя:** например, `ivan`
   - **Лимит трафика:** например, 100 ГБ (или без лимита)
   - **Срок действия:** например, +30 дней (или бессрочно)
   - **Входящие подключения:** отметьте галочкой `Main`
3. Сохраните.

### Как отдать доступ клиенту

**Способ 1 — прямой конфиг/QR (работает сразу, без домена):**
раскройте пользователя в панели → кнопка показа конфигурации →
скопируйте ссылку `vless://...` или покажите **QR-код**.
Клиент в Happ: **«+» → «Вставить из буфера»** (или «Сканировать QR»).

**Способ 2 — подписка (рекомендуется для сервиса, нужен домен):**
после привязки домена (шаг 7) у пользователя появляется «Ссылка-подписка».
Зашифруйте её для клиента:

```bash
bash /root/happ-vpn-service/happ-encode.sh "https://ВАШ_ДОМЕН:8443/sub/ТОКЕН"
```

Получите строку `happ://crypto:...` — отправьте её клиенту. Он вставляет её в Happ
и **не видит** адрес вашего сервера; при обновлениях на сервере подписка
у клиента обновится автоматически.

> 💡 Подписка лучше прямой ссылки: сменили ключи/добавили сервер — у всех
> клиентов с подпиской всё обновится само, ничего перевыпускать не надо.

---

## 6. Что делает клиент

1. Ставит **Happ**: [App Store](https://apps.apple.com/app/happ-proxy-utility/id6504287215) /
   [Google Play](https://play.google.com/store/apps/details?id=com.happproxy);
   версии для Windows/macOS/Linux — на сайте проекта.
2. **«+» → «Вставить из буфера»** → вставляет `happ://...`, `vless://...` или сканирует QR.
3. Выбирает сервер → большая круглая кнопка → разрешает VPN-профиль (система спросит один раз).
4. Готово.

---

## 7. Привязка домена (для режима «сервис» — очень рекомендую)

Нужна, чтобы раздавать **подписки** (автообновление у клиентов) и вообще выглядеть
как нормальный сервис. Домен стоит ~1–10 €/год у любого регистратора.

1. Купите домен и у регистратора создайте **A-запись**: `ваш-домен.ру → IP сервера`.
   Подождите 5–30 минут, пока запись применится.
2. На сервере:

```bash
sudo bash /root/happ-vpn-service/setup-domain.sh ваш-домен.ру ваш@email
```

Скрипт сам: проверит DNS → выпустит сертификат Let's Encrypt → включит HTTPS
для подписок на порту 8443 → настроит автопродление сертификата.

После этого в настройках подписок панели (`/var/lib/marzban/.env`) уже прописан
адрес `https://ваш-домен:8443/sub` — ссылки-подписки станут рабочими.

## 8. Безопасность (сделайте обязательно)

```bash
sudo bash /root/happ-vpn-service/harden.sh
```

Откроются только порты **22** (SSH), **443** (клиенты) и **80**. Порт панели наружу не торчит.

Дополнительные рекомендации:

- Настройте доступ по **SSH-ключу** и отключите вход по паролю:
  `adduser vpnuser && usermod -aG sudo vpnuser`, скопируйте ключ в
  `/home/vpnuser/.ssh/authorized_keys`, затем в `/etc/ssh/sshd_config`:
  `PasswordAuthentication no` → `systemctl restart ssh`.
- Смените пароль панели в любой момент: правка `SUDO_PASSWORD` в
  `/var/lib/marzban/.env` → `docker compose -f /opt/marzban-service/docker-compose.yml restart`.
- Для приличного вида у клиентов — свой домен (шаг 7).

## 9. Обслуживание

| Задача | Команда |
|---|---|
| Проверка «всё ли живо» | `bash /root/happ-vpn-service/health.sh` |
| Бэкап (база + конфиги) | `sudo bash /root/happ-vpn-service/backup.sh` |
| Логи | `docker compose -f /opt/marzban-service/docker-compose.yml logs -f --tail=100` |
| Перезапуск | `docker compose -f /opt/marzban-service/docker-compose.yml restart` |
| Обновление панели | `docker compose -f /opt/marzban-service/docker-compose.yml pull && docker compose -f /opt/marzban-service/docker-compose.yml up -d` |
| Юзеры из консоли | `marzban-cli` (например, `marzban-cli list-users`) |
| Полное удаление | `sudo bash /root/happ-vpn-service/uninstall.sh` |

Ежедневный бэкап:

```bash
sudo crontab -e
# добавьте строку:
0 4 * * * /root/happ-vpn-service/backup.sh >/dev/null 2>&1
```

Бэкапы лежат в `/root/marzban-backup-*.tar.gz` — периодически скачивайте их к себе:
`scp root@IP:/root/marzban-backup-*.tar.gz ~/backups/`

## 10. Частые проблемы

| Симптом | Причина / решение |
|---|---|
| Клиент не подключается | Порт 443 закрыт у хостера? `sudo ufw status`; `bash health.sh` |
| Панель не открывается по туннелю | `docker ps` — контейнер должен быть `Up`; смотрим логи |
| Подписка у клиента не обновляется | Нужен домен + `setup-domain.sh` (клиент должен ходить по настоящему HTTPS) |
| Happ пишет «неверный формат» | Отдавайте строку `happ://...` или `vless://...` целиком, без обрезок |
| Сервер «забанили» (не пингуется из РФ) | Некоторые IP блокируются: смените IP у хостера (обычно делается в панели хостинга) или добавьте второй сервер |
| Медленно | Попробуйте другой `dest/SNI` в настройках inbound; `htop` — не упирается ли сервер в CPU |
| Кончился трафик/срок у клиента | Панель сама отключает пользователя; продлите срок/лимит в свойствах юзера |

## 11. Масштабирование в бизнес

1. **Вручную** (этот комплект): клиент платит → вы создаёте/продлеваете юзера.
   Удобно до ~30–50 клиентов.
2. **Телеграм-бот**: в `.env` есть поля `TELEGRAM_ID` / `TELEGRAM_API_TOKEN` —
   привязывают бота к панели. Плюс существуют готовые боты-магазины для Marzban
   (проект `Marzshop`, боты с оплатой), которые сами продают и выдают подписки.
3. **Приём оплаты**: для РФ — ЮKassa, CloudPayments, крипта; для зарубежа — Stripe.
4. **Больше серверов**: в панели есть раздел **Nodes** — можно подключить дополнительные
   сервера и раздавать клиентам выбор локации.
